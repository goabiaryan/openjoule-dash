# Data Center Planner

Interactive app: stack facility blocks, derive power / cooling / network / space, program brief, charts, matrix, compare, ops.

```bash
cd openjoule-dash
npm install
npm run dev
```

Tabs: **Build** · **Program** · **Scale** · **Operate**. URL hash syncs view (`#build`, `#program`, `#scale`, `#operate`; `#size` → `#scale`, `#path` → `#operate`).

```bash
npm run build && npm run preview
```
